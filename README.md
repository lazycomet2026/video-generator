# 视频生成器 Video Generator

一个基于浏览器的视频特效生成工具，支持多种视觉特效，可将静态图片转化为动态视频。

## ✨ 功能特性

- **📤 图片上传** — 支持本地文件选择和相机拍照
- **🎨 6种特效** — 水波纹、粒子、网格、爆炸、扫描线、霓虹灯
- **⏱️ 时长可调** — 4~30秒自由设置
- **📐 自适应比例** — 自动识别横屏/竖屏图片
- **👁️ 实时预览** — 生成过程可视化展示
- **📊 进度条** — 实时显示生成进度
- **💾 一键下载** — 生成完成后直接导出视频

## 🎬 支持的特效

| 特效 | 说明 |
|------|------|
| 🌊 水波纹 | 动态波浪扭曲效果 |
| ✨ 粒子 | 漂浮粒子动画 |
| 🔲 网格 | 动态网格变形 |
| 💥 爆炸 | 粒子爆炸扩散 |
| 📺 扫描线 | CRT 扫描线效果 |
| 💡 霓虹灯 | 霓虹发光动画 |

## 🚀 使用方法

### 方式一：浏览器直接打开
1. 下载 `index.html` 文件
2. 双击用浏览器打开
3. 上传图片 → 选择特效 → 点击生成

### 方式二：本地服务器
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 操作流程
1. 点击「选择图片」上传图片（或拍照）
2. 勾选需要的特效（可多选组合）
3. 拖动滑块调整视频时长（4~30秒）
4. 点击「生成视频」按钮
5. 等待进度条完成
6. 点击「下载视频」保存到本地

## 📋 技术栈

- **前端**: 原生 HTML5 + CSS3 + JavaScript
- **Canvas**: Canvas 2D API 渲染特效
- **视频编码**: MediaRecorder API
- **兼容性**: Chrome、Edge、Safari 等现代浏览器

## ⚠️ 注意事项

- 视频生成在浏览器本地完成，不上传服务器
- 建议图片不超过 10MB
- 特效较多时生成时间可能较长
- 移动端建议横屏使用
