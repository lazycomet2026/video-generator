# 视频生成器 Video Generator

一个基于浏览器的视频特效生成工具，支持多种视觉特效，可将静态图片转化为动态视频。

## 功能特性

- **图片上传** — 支持本地文件选择和相机拍照
- **6种特效** — 水波纹、粒子、网格、爆炸、扫描线、霓虹灯
- **时长可调** — 4~30秒自由设置
- **自适应比例** — 自动识别横屏/竖屏图片
- **实时预览** — 生成过程可视化展示
- **进度条** — 实时显示生成进度
- **一键下载** — 生成完成后直接导出视频

## 使用方法

直接打开 `index.html` 文件即可使用，无需安装任何依赖。
